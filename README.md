# 答题卡智能判卷（H5 版 · PWA 可离线）

手机拍照 → 自动识别 → 自动出分，全部在浏览器本地完成，**不需要服务器、不需要注册任何账号**。

## 文件说明

| 文件 | 作用 |
|------|------|
| `index.html` | 主程序（判卷 / 考试管理 / 统计导出 / 帮助） |
| `template.html` | 答题卡模板打印页（A4，50 题 × A–E，四角带定位块） |
| `layout.js` | 版式规范（模板与识别共用，保证两者严格匹配） |
| `app.js` | 识别与判卷核心逻辑（OpenCV.js） |
| `lib/opencv.js` | 识别引擎（本地内置，无需联网加载） |
| `manifest.webmanifest` | PWA 配置（手机"添加到主屏幕"用） |
| `sw.js` | 离线缓存（首次加载后可断网使用） |
| `icons/icon.svg` | APP 图标 |
| `vercel.json` / `_headers` / `package.json` | 部署配置（Vercel/Netlify/Cloudflare 直接识别） |
| `DEPLOY.md` | 4 种免费永久部署方案（GitHub Pages / Vercel / Cloudflare / 腾讯云） |
| `answers.sample.json` | 答案配置示例 |

## 使用步骤

1. **打印答题卡**：电脑浏览器打开 `template.html`，右上角输入考试名称，点击打印。
   打印设置：**A4 · 100% 缩放 · 黑白**。四角黑色定位方块必须完整。
2. **录入标准答案**：打开 `index.html` →「考试管理」→ 填考试名称 →「录入答案」逐题点选 → 保存。
   也可用 JSON 文件导入导出（格式见 `answers.sample.json`）。
3. **拍照判卷**：「判卷」页 → 选择考试 → 点拍照按钮（可一次选多张照片）→ 自动出分。
4. **核对与调整**：每张结果可展开「矫正识别图」检查识别是否准确；分数普遍偏低把阈值调高，误判空白调低，然后点「按新阈值重新判卷」（秒级完成，无需重新拍照）。
5. **导出成绩**：「统计导出」页下载 CSV，Excel 直接打开；查看各题错误率用于讲评。

## 拍摄要求（识别率关键）

- 整张卡完整入镜，**四角黑块不能被裁掉或遮挡**
- 光线均匀，避免阴影盖住答题区
- 选项必须涂满涂黑；涂改擦干净，避免残影
- 一张照片只放一张答题卡

## 数据安全

所有数据（考试答案、判卷记录）只存在本机浏览器 localStorage 中，不上传任何服务器。
换手机前请用「考试管理 → 导出当前答案」备份 JSON 文件。

## 技术架构

纯前端方案：HTML + JavaScript + OpenCV.js（WebAssembly）。
识别流程：照片 → 纸张轮廓透视矫正 → 四角定位块二次精矫正 → 逐格涂黑率测量（Otsu 二值化）→ 阈值判定 → 与标准答案比对 → 出分与统计。
